# Dashboard ANDE - Sistema de Monitoreo de Frecuencia Eléctrica

## 📋 Descripción
Dashboard profesional para monitoreo y análisis de frecuencia eléctrica de la Administración Nacional de Electricidad (ANDE).

## 🚀 Características
- Visualización de datos en tiempo real
- Múltiples gráficos interactivos
- Filtros avanzados
- Tablas expandibles
- Exportación de datos
- Diseño responsive

## 🛠️ Tecnologías
- **Backend**: Node.js, Express, SQLite
- **Frontend**: HTML5, CSS3, JavaScript Vanilla
- **Gráficos**: Chart.js
- **Base de datos**: SQLite
